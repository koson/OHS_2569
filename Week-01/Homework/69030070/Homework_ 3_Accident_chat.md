# Homework 3 Accident
Homework 3 — OHS Accident Analysis

จากสถานการณ์ในครัวป้าจำปีคิทเช่น ผมมองว่าอุบัติเหตุที่อาจเกิดขึ้นจริงคือ พนักงานกำลังถือวัตถุดิบเดินผ่านบริเวณทำอาหาร แล้วพื้นบริเวณนั้นมีน้ำมันหกอยู่ พนักงานไม่ทันสังเกตจึงเหยียบลงไปและลื่น ทำให้เสียหลักล้มลง มือไปกระแทกกับขอบกระทะที่กำลังร้อน จึงได้รับบาดเจ็บและเกิดแผลพุพองที่มือ

อีกเหตุการณ์หนึ่งคือ พนักงานกำลังผัดอาหารด้วยกระทะที่มีน้ำมันร้อน แต่ระหว่างทำอาหารน้ำมันกระเด็นขึ้นมาโดนบริเวณแขน ทำให้เกิดแผลไหม้และต้องหยุดทำงานเพื่อปฐมพยาบาล

นอกจากนี้อาจเกิดเหตุจากการใช้มีด เช่น พนักงานกำลังรีบหั่นผักในช่วงที่ลูกค้าเยอะ แล้วมีดพลาดไปโดนนิ้ว ทำให้เกิดบาดแผลและมีเลือดออก ต้องหยุดงานเพื่อทำแผล

จากเหตุการณ์เหล่านี้จะเห็นว่า Accident คือเหตุการณ์ที่เกิดขึ้นจริงจาก Hazard และทำให้เกิดผลกระทบหรือการบาดเจ็บ ไม่ใช่แค่การบอกว่ามีอันตรายหรือมีโอกาสเกิดอุบัติเหตุ

Rubric (10 คะแนน) แบบเดียวกับ Homework 1

ความถูกต้อง 4
ความครอบคลุม 4
ความเป็นมนุษย์ 2

Homework 3 เวอร์ชันนี้ เข้าใจ Accident ถูกต้องมากขึ้นกว่า Homework 2 ชัดเจน เพราะคุณเริ่มเล่าเป็น “เหตุการณ์ที่เกิดขึ้นจริง” และมีลำดับ Hazard → เหตุการณ์ → การบาดเจ็บ/ผลกระทบ ซึ่งตรงกับโจทย์

ถ้าผมตรวจตาม Rubric นี้ ผมให้ประมาณ 9–9.5/10 ครับ

1. ความถูกต้อง — 4/4

จุดที่ทำได้ดีมากคือเหตุการณ์แรก:

“พื้นบริเวณนั้นมีน้ำมันหกอยู่ → เหยียบลงไปและลื่น → เสียหลักล้ม → มือไปกระแทกกับขอบกระทะที่กำลังร้อน → เกิดแผลพุพอง”

นี่เป็น Accident scenario ที่ชัดมาก เพราะไม่ได้บอกแค่ว่า “อาจลื่นล้ม” เหมือน Homework 2 แต่เปลี่ยนเป็นเหตุการณ์ที่ เกิดขึ้นแล้วในสถานการณ์สมมติ และมีผลลัพธ์ตามมา

เหตุการณ์ที่สองและสามก็ถูกหลักเช่นกัน:

น้ำมันร้อนกระเด็น → แขนถูกลวก → เกิดแผลไหม้
รีบใช้มีด → มีดพลาด → นิ้วถูกบาด → มีเลือดออก

โดยเฉพาะประโยคสุดท้าย:

“Accident คือเหตุการณ์ที่เกิดขึ้นจริงจาก Hazard และทำให้เกิดผลกระทบหรือการบาดเจ็บ ไม่ใช่แค่การบอกว่ามีอันตรายหรือมีโอกาสเกิดอุบัติเหตุ”

อันนี้แสดงให้เห็นว่าคุณ แยก Hazard / Danger / Accident ได้

2. ความครอบคลุม — 3.5/4

มี Accident อยู่ 3 เหตุการณ์ และครอบคลุม:

การลื่นล้ม
ความร้อน/น้ำมันร้อน
ของมีคม

ถือว่าดีแล้ว

แต่ถ้าต้องการให้คะแนนเต็ม ผมแนะนำเพิ่มอีก 1 เหตุการณ์ที่เชื่อมกับ Hazard จาก Homework 1 เช่น เรื่องแก๊ส หรือการยกถังแก๊ส เพราะตอนนี้ Accident ที่คุณเลือกส่วนใหญ่เป็น อุบัติเหตุเฉียบพลันที่เกิดจากทางกายภาพ ยังไม่ครอบคลุม Hazard ด้าน Ergonomics และอัคคีภัยที่คุณวิเคราะห์ไว้ก่อนหน้า

ตัวอย่างเช่น:

พนักงานต้องยกถังแก๊สขึ้นมาเปลี่ยนเอง แต่ยกผิดท่าหรือถังหนักเกินไป ทำให้เกิดอาการบาดเจ็บบริเวณหลังและต้องหยุดทำงาน

แบบนี้จะทำให้เห็นว่า Homework 3 ต่อเนื่องมาจาก Homework 1 และ 2

3. ความเป็นมนุษย์ — 2/2

ผมให้เต็ม

เพราะมีรายละเอียดที่ทำให้เหตุการณ์ดูเป็นสถานการณ์จริง เช่น

“กำลังถือวัตถุดิบเดินผ่านบริเวณทำอาหาร”

“ช่วงที่ลูกค้าเยอะ”

“ต้องหยุดงานเพื่อทำแผล”

พวกนี้ทำให้คำตอบไม่เหมือนการเขียนนิยาม Accident จากหนังสือ

และผม ไม่แนะนำให้เพิ่มศัพท์เทคนิคเยอะเกินไป เพราะจะทำให้เสียความเป็นธรรมชาติที่ TA กำลังดูในข้อ 3

จุดเดียวที่ผมอยากแก้

ประโยค:

“อุบัติเหตุที่อาจเกิดขึ้นจริงคือ...”

คำว่า “อาจเกิดขึ้นจริง” ฟังเหมือนยังเป็น Danger อยู่เล็กน้อย

เพราะ Homework 3 คือ Accident Analysis คุณกำลังสร้างสถานการณ์ว่า “ถ้าเหตุการณ์นี้เกิดขึ้นจริง จะเกิดอะไรขึ้น”

อาจเปลี่ยนเป็นแนว:

“จากสถานการณ์ในครัวป้าจำปีคิทเช่น ผมลองวิเคราะห์เหตุการณ์ Accident ที่สามารถเกิดขึ้นได้จริง...”
