# Week 05 แบบทดสอบทบทวนความรู้ ส่วนที่ 1

**เรื่องที่เลือก:** เรื่องที่ 2, 4 และ 5

## เรื่องที่ 2 งานครัวอุตสาหกรรมและบริการอาหาร

| ประเด็นที่วินิจฉัย | รายละเอียดจากสถานการณ์ | ความหมาย / เหตุผลสนับสนุน |
|---|---|---|
| 1. การกระทำที่ไม่ปลอดภัย (Unsafe Act) | เชฟเป้นำไก่ที่ยังมีน้ำแข็งเกาะลงทอดในน้ำมันร้อนทันที | น้ำแข็งและน้ำทำให้น้ำมันร้อนกระเด็น เสี่ยงถูกลวก |
| 2. สภาพการณ์ที่ไม่ปลอดภัย (Unsafe Condition) | พื้นมีคราบน้ำมันและน้ำขัง ไม่มีแผ่นยางกันลื่นหรือป้ายเตือน | ทำให้พื้นลื่นและพนักงานมีโอกาสหกล้ม |
| 3. Near Miss | เชฟเป้เหยียบพื้นลื่นจนเกือบล้ม แต่จับขอบโต๊ะไว้ทัน | เป็นเหตุการณ์ที่เกือบเกิดอุบัติเหตุ แต่ไม่มีผู้บาดเจ็บหรือทรัพย์สินเสียหาย |
| 4. Accident | เชฟเป้ลื่นล้ม ทำให้น้ำมันร้อนกระเด็นถูกแขนจนพุพอง | เกิดการบาดเจ็บจริงจากน้ำมันร้อนลวก |

## เรื่องที่ 4 งานเกษตรกรรมและการใช้สารเคมีกำจัดศัตรูพืช

| ประเด็นที่วินิจฉัย | รายละเอียดจากสถานการณ์ | ความหมาย / เหตุผลสนับสนุน |
|---|---|---|
| 1. การกระทำที่ไม่ปลอดภัย (Unsafe Act) | ลุงสมหมายฉีดพ่นสารเคมีโดยไม่สวม PPE ที่เหมาะสม และเดินฉีดพ่นในทิศทางใต้ลม | ทำให้ละอองสารเคมีสัมผัสร่างกายและเสี่ยงสูดดมสารพิษ |
| 2. สภาพการณ์ที่ไม่ปลอดภัย (Unsafe Condition) | สายยางถังพ่นยาเก่าแตกลายงาและข้อต่อรั่วซึม | ทำให้สารเคมีรั่วไหลและสัมผัสผิวหนังได้ |
| 3. Near Miss | ขณะเตรียมฉีดพ่น ลุงสมหมายพบสายยางรั่วและหยุดใช้งานก่อนสารเคมีสัมผัสร่างกาย | เกือบได้รับอันตรายจากสารเคมี แต่หยุดได้ทันและไม่มีความเสียหาย |
| 4. Accident | สารเคมีจากสายยางรั่วเปื้อนผิวหนัง ทำให้ลุงสมหมายเกิดอาการพิษและต้องเข้ารับการรักษา | เกิดการบาดเจ็บหรือเจ็บป่วยจากการสัมผัสสารเคมีจริง |

## เรื่องที่ 5 งานขนส่งสินค้าทางน้ำและท่าเรือ

| ประเด็นที่วินิจฉัย | รายละเอียดจากสถานการณ์ | ความหมาย / เหตุผลสนับสนุน |
|---|---|---|
| 1. การกระทำที่ไม่ปลอดภัย (Unsafe Act) | ธนาบังคับเครนยกตู้คอนเทนเนอร์ข้ามทางเดินพนักงานโดยไม่ส่งสัญญาณเตือน | เสี่ยงทำให้พนักงานด้านล่างถูกสิ่งของตกทับ |
| 2. สภาพการณ์ที่ไม่ปลอดภัย (Unsafe Condition) | ลวดสลิงเครนชำรุด มีเส้นลวดหลุดลุ่ยและสึกหรอ แต่ยังไม่ได้เปลี่ยน | อุปกรณ์ยกไม่ปลอดภัยและเสี่ยงต่อการขาดขณะรับน้ำหนัก |
| 3. Near Miss | ตู้คอนเทนเนอร์แกว่งเข้าใกล้พนักงาน แต่พนักงานหลบได้ทันโดยไม่มีความเสียหาย | เกือบเกิดอุบัติเหตุ แต่ไม่มีผู้บาดเจ็บหรือทรัพย์สินเสียหาย |
| 4. Accident | ลวดสลิงขาดขณะยก ทำให้ตู้คอนเทนเนอร์ตกลงมาทับอุปกรณ์ในท่าเรือเสียหาย | เกิดอุบัติเหตุและมีทรัพย์สินเสียหายจริง |
