## Homework: วิเคราะห์ Danger / Accident / Near Miss
จาก Hazard ที่กำหนด ให้คุณวิเคราะห์ 3 มิติ ได้แก่
- Danger (อันตรายที่อาจเกิดขึ้น)
- Accident (เหตุการณ์ที่เกิดขึ้นจริง)
- Near Miss (เหตุเฉียดที่เกือบเกิด แต่ยังไม่เกิด)
ให้เขียนลงในตารางที่กำหนด โดยใช้ภาษาของตัวเอง ห้ามท่องนิยาม ห้ามคัดลอกทฤษฎี ให้เขียนแบบภาษาคนทั่วไป เหมือนเล่าเหตุการณ์ให้เพื่อนฟัง
สามารถส่งตรวจคราวเดียวทั้งหมดหรือครั้งละหมวดก็ได้
คุณสามารถส่งคำตอบใหม่ได้เรื่อยๆ จนกว่าจะพอใจคะแนน TA AI จะตรวจให้ทุกครั้งแบบเข้มงวด

## แนวทางการเขียน Danger, Accident และ Near Miss
### 👉 วิธีเขียน Danger ให้ถูกต้อง
Danger = “โอกาสที่จะเกิดเหตุ” ต้องมี **สถานการณ์เฉพาะเจาะจง** เช่น
- ตอนเดินถือของร้อน
- ตอนเดินสวนกันในครัวแคบ
- ตอนรีบทำงาน
ห้ามเขียนว่า “มีโอกาสลื่นล้ม” เฉย ๆ เพราะมันสั้นเกินไป ต้องระบุสถานการณ์ที่เจาะจงด้วย

### 👉 วิธีเขียน Accident ให้ถูกต้อง
Accident = “เหตุการณ์จริงที่เกิดขึ้นแล้ว” ต้องมี **ลำดับเหตุการณ์** เช่น
1. เหยียบน้ำมัน
2. ลื่นล้ม
3. มือกระแทกกระทะร้อน
4. อาหารหก
ห้ามเขียนว่า “ลื่นล้มเพราะเดินไม่ระวัง” เพราะเป็นการโทษคน และไม่ใช่หลัก OHS

### 👉 วิธีเขียน Near Miss ให้ถูกต้อง
Near Miss = “เกือบเกิด แต่ไม่เกิด” ต้องมี **สิ่งที่ช่วยให้ไม่เกิดเหตุ** เช่น
- จับโต๊ะทัน
- ยกเท้าหลบทัน
- เพื่อนดึงตัวไว้
ห้ามเขียนว่า “เกือบล้ม” เฉย ๆ ต้องบอกว่า “เพราะอะไรถึงไม่ล้ม”

#  **หมวด 1 — ร้านอาหาร / ครัว (12 ข้อ)**
### K1. พื้นครัวมันลื่นเพราะน้ำมันกระเด็นตอนผัดไฟแรง
#### คำตอบ (ตัวอย่าง)

| รายการ    | รายละเอียด                                                                                                                                    |
| --------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| Danger    | พนักงานมีโอกาสลื่นล้มตอนเดินถือจานร้อน โดยเฉพาะช่วงที่ครัวแคบและต้องเดินสวนกัน เพราะพื้นมีน้ำมันเคลือบอยู่ทำให้เท้าไถลง่าย                    |
| Accident  | พนักงานเดินถือชามร้อนแล้วเหยียบน้ำมัน ทำให้ลื่นล้ม มือกระแทกกระทะร้อนจนพอง และอาหารหกกระจายเต็มพื้น เกิดความเสียหายทั้งต่อร่างกายและงานในครัว |
| Near Miss | พนักงานเดินผ่านจุดที่มีน้ำมันแล้วรู้สึกเท้าไถล แต่จับโต๊ะทันเลยไม่ล้ม เหตุการณ์นี้เกือบจะกลายเป็นอุบัติเหตุจริง แต่โชคดีที่ควบคุมตัวเองได้ทัน |

### T8. พื้นลานโหลดมีน้ำขังจากฝนตก
#### คำตอบ
| รายการ | รายละเอียด |
| --------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| Danger | พนักงานมีโอกาสสไลด์ลื่นล้มขณะยกของหนัก หรือล้อรถโฟร์คลิฟท์ลื่นไถล (Hydroplaning) เบรกไม่อยู่ขณะบรรทุกสินค้า |
| Accident | พนักงานเดินแบกกล่องผ่านแอ่งน้ำ ลื่นไถลล้มหงายหลัง หัวกระแทกพื้นลานอย่างแรง ลิ้มรสความเจ็บปวดและกล่องทับหน้าอก |
| Near Miss | พนักงานเหยียบแอ่งน้ำลึกแล้วเท้าสไลด์ไปข้างหน้า แต่โชคดีที่ปล่อยกล่องลงพื้นและเอามือยันข้างรถบรรทุกไว้ทัน ตัวเลยไม่ล้ม |

### T9. พนักงานใช้โทรศัพท์ขณะเดินในพื้นที่ที่มีรถวิ่ง
#### คำตอบ
| รายการ | รายละเอียด |
| --------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| Danger | พนักงานเสียสมาธิและทัศนวิสัย ไม่ทันสังเกตเห็นรถโฟร์คลิฟท์หรือรถบรรทุกที่กำลังเคลื่อนตัวเข้ามาหา |
| Accident | พนักงานก้มหน้าพิมพ์งานเดินก้าวเข้าหาช่องทางวิ่งโฟร์คลิฟท์ โดนงารถโฟร์คลิฟท์ชนกระแทกเข้าที่ลำตัวล้มลงบาดเจ็บ |
| Near Miss | พนักงานก้มมองจอเดินสะเปะสะปะเกือบตัดหน้ารถเข็นไฟฟ้า แต่คนขับบีบแตรเสียงดังลั่น พนักงานสะดุ้งหยุดก้าวทันก่อนโดนชน |

### T10. ไฟส่องสว่างในลานจอดเสีย ทำให้มุมมืดหลายจุด
#### คำตอบ
| รายการ | รายละเอียด |
| --------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| Danger | ทัศนวิสัยต่ำ ทำให้มองไม่เห็นสิ่งกีดขวางบนพื้น สายตาปรับแสงไม่ทัน เสี่ยงต่อการสะดุด ลื่นล้ม หรือชนกับรถที่วิ่งอยู่ |
| Accident | พนักงานเดินในมุมมืดสะดุดแท่นปูนกั้นล้อที่มองไม่เห็น ล้มหน้าคะมำแผลถลอกปอกเปิกและข้อเท้าพลิกอักเสบ |
| Near Miss | พนักงานเดินในมุมมืดแล้วเท้าไปกะเทาะโดนแท่นปูน แต่ชักเท้ากลับและกางแขนทรงตัวทัน เลยไม่ล้มลงไปกองกับพื้น |

### T11. รถบรรทุกจอดบนพื้นเอียงโดยไม่ใช้ตัวหนุนล้อ
#### คำตอบ
| รายการ | รายละเอียด |
| --------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| Danger | ระบบเบรกลมหรือเบรกมืออาจขัดข้อง ทำให้รถบรรทุกไหลถอยหลังลงตามความชันไปชนอาคาร พนักงาน หรือรถคันอื่น |
| Accident | เบรกมือรถบรรทุกหลุดขณะจอดบนเนิน รถไหลถอยหลังชนพนักงานที่กำลังยืนตรวจเอกสารท้ายรถ อัดติดกับผนังบาดเจ็บสาหัส |
| Near Miss | รถบรรทุกเริ่มค่อยๆ ไหลถอยหลังนิดหน่อย คนขับตาไวรีบกระโดดขึ้นรถเหยียบเบรกเท้าและดึงเบรกมือซ้ำได้ทันก่อนรถจะไหลชนใคร |

### T12. พนักงานขี่มอเตอร์ไซค์ในลานขนส่งโดยไม่ใส่หมวกกันน็อก
#### คำตอบ
| รายการ | รายละเอียด |
| --------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| Danger | เมื่อเกิดอุบัติเหตุล้มหรือชน ศีรษะจะกระแทกพื้นหรือตัวรถโดยตรง ไม่มีสิ่งป้องกัน ความเสี่ยงบาดเจ็บทางสมองถึงชีวิตสูง |
| Accident | มอเตอร์ไซค์ลื่นคราบน้ํามันล้มในลานขนส่ง ศีรษะพนักงานกระแทกพื้นคอนกรีตอย่างแรง กะโหลกร้าวต้องเข้าห้องฉุกเฉินด่วน |
| Near Miss | มอเตอร์ไซค์เสียหลักสะดุดร่องพื้นจนตัวรถตะแคง แต่พนักงานเอาเท้าข้างหนึ่งยันพื้นทรงตัวไว้ทัน รถไม่ล้มและศีรษะไม่กระแทก |
