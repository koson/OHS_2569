# Week 06: การบ้านเปรียบเทียบงบประมาณกฎหมายความปลอดภัยกับค่าใช้จ่าย PPE

## 1. งบประมาณในการร่างกฎหมายความปลอดภัย

พระราชบัญญัติความปลอดภัย อาชีวอนามัย และสภาพแวดล้อมในการทำงาน เป็นกฎหมายที่จัดทำขึ้นเพื่อกำหนดมาตรฐานและหน้าที่ด้านความปลอดภัยในการทำงาน ช่วยคุ้มครองลูกจ้างและลดอุบัติเหตุในสถานประกอบการ

กฎหมายฉบับที่ประกาศใช้จริงคือ **พ.ศ. 2554** ไม่ใช่ พ.ศ. 2551 ตามตัวอย่างในโจทย์ อย่างไรก็ตาม จากข้อมูลที่ค้นคว้า ยังไม่พบตัวเลขงบประมาณที่แยกเฉพาะสำหรับการร่างกฎหมายฉบับนี้

## 2. ค่าใช้จ่ายในการซื้อ PPE

จากงานวิจัยการประชุมวิชาการวิศวกรรมศาสตร์และเทคโนโลยี มทร.พระนคร ครั้งที่ 6 พ.ศ. 2565 พบตัวอย่างราคาของอุปกรณ์ PPE ดังนี้

| อุปกรณ์ | ราคา (บาท) |
|---|---:|
| หมวกนิรภัย | 170 |
| ผ้าปิดจมูก | 14 |
| รองเท้าพื้นยางหุ้มส้น | 1,400 |
| ถุงมือผ้า | 70 |
| เข็มขัดนิรภัย | 1,170 |
| แว่นตานิรภัย | 140 |
| ถุงมือหนัง | 232 |
| ถุงมือยาง | 100 |
| รองเท้านิรภัย | 950 |
| แว่นตากรองแสง | 135 |
| **รวม** | **4,381** |

นอกจากนี้ งานวิจัยเสนอให้ประมาณค่าใช้จ่ายจัดซื้อ PPE ที่ 350 บาทต่อคน และเผื่อค่าเสียหายหรือชำรุดอีก 20% รวมเป็น 420 บาทต่อคน

ตัวอย่าง หากมีพนักงาน 100 คน จะมีค่าใช้จ่ายประมาณ 42,000 บาท

## 3. เปรียบเทียบและสรุป

การร่างกฎหมายเป็นการลงทุนเพื่อสร้างมาตรฐานความปลอดภัยให้ครอบคลุมการทำงานในระดับประเทศ ส่วนการซื้อ PPE เป็นค่าใช้จ่ายที่สถานประกอบการต้องรับผิดชอบเพื่อป้องกันอันตรายให้กับพนักงานโดยตรง และอาจต้องซื้อทดแทนเมื่ออุปกรณ์ชำรุดหรือหมดอายุ

แม้จะไม่สามารถเปรียบเทียบเป็นจำนวนเงินโดยตรงได้ เนื่องจากไม่มีข้อมูลงบประมาณการร่างกฎหมายที่แน่ชัด แต่ทั้งสองส่วนมีความสำคัญต่อการป้องกันอุบัติเหตุ โดยกฎหมายเป็นกรอบกำหนดมาตรฐาน ส่วน PPE เป็นอุปกรณ์ที่ช่วยลดความเสี่ยงในการปฏิบัติงาน
