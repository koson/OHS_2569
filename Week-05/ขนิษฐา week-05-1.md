| 2. สภาพการณ์ที่ไม่ปลอดภัย (Unsafe Condition)     | 1. แผ่นฉนวนกั้นบัสบาร์แตกหักชำรุด 2. มีแท่งบัสบาร์นำไฟฟ้าเปลือย 3. ระบบอาจยังมีกระแสไฟฟ้าหลงเหลืออยู่                                                                                                 | เป็นสภาพแวดล้อมที่มีความเสี่ยงทางวิศวกรรม เนื่องจากอุปกรณ์ป้องกันไฟฟ้าชำรุดและมีส่วนที่มีกระแสไฟฟ้าเปิดเผย                    |
| 3. กรณีที่เป็น Near Miss                         | ขณะที่ช่างนพใช้ไขควงขันสกรู ไขควงเกิดสัมผัสกับส่วนที่มีกระแสไฟฟ้า ทำให้เกิดประกายไฟและไฟฟ้าลัดวงจร แต่ช่างนพสามารถถอยออกมาได้ทันโดยไม่ได้รับบาดเจ็บ                                                   | จัดเป็น Near Miss เพราะเป็นเหตุการณ์ที่เกือบทำให้เกิดอุบัติเหตุร้ายแรง แต่ไม่มีผู้ได้รับบาดเจ็บหรือเกิดความสูญเสีย            |
| 4. กรณีที่เป็น Accident                          | ช่างนพสัมผัสกับส่วนที่มีกระแสไฟฟ้าขณะซ่อมแซมตู้ควบคุม ทำให้เกิดไฟฟ้าดูดและได้รับบาดเจ็บ รวมถึงอาจเกิดแผลไหม้จากกระแสไฟฟ้า                                                                             | จัดเป็น Accident เพราะเกิดอุบัติเหตุขึ้นจริง ส่งผลให้ผู้ปฏิบัติงานได้รับบาดเจ็บและอาจทำให้เครื่องจักรหรืออุปกรณ์เสียหาย       |

เรื่องที่ 3 งานเชื่อมตัดโลหะในสถานที่อับอากาศ

(Welding in Confined Space)

| ประเด็นที่วินิจฉัย                           | รายละเอียดจากสถานการณ์                                                                                                                                                                                                 | ความหมาย / เหตุผลสนับสนุน                                                                                                 |
| -------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| 1. การกระทำที่ไม่ปลอดภัย (Unsafe Act)        | 1. ไม่ตรวจวัดระดับก๊าซพิษและปริมาณออกซิเจนก่อนเข้าทำงาน 2. ไม่ใช้อุปกรณ์ช่วยหายใจที่เหมาะสมกับสภาพอันตราย 3. ไม่ตรวจสอบความพร้อมของระบบระบายอากาศ 4. ตัดสินใจทำงานโดยประเมินว่าใช้เวลาไม่นานจึงละเลยมาตรการความปลอดภัย | เป็นพฤติกรรมเสี่ยงที่อาจทำให้ได้รับก๊าซพิษ ขาดออกซิเจน หรือเกิดอันตรายจากควันและความร้อนภายในพื้นที่อับอากาศ              |
| 2. สภาพการณ์ที่ไม่ปลอดภัย (Unsafe Condition) | 1. พัดลมระบายอากาศ (Blower) ชำรุด 2. ไม่มีการถ่ายเทอากาศภายในถัง 3. เป็นพื้นที่ปิดที่อาจสะสมก๊าซพิษและควันเชื่อม 4. มีประกายไฟและความร้อนจากงานเชื่อม                                                                  | เป็นสภาพแวดล้อมที่มีความเสี่ยงสูง เนื่องจากอากาศภายในพื้นที่อับอากาศอาจมีออกซิเจนไม่เพียงพอหรือมีก๊าซอันตรายสะสม          |
| 3. กรณีที่เป็น Near Miss                     | ขณะที่ช่างชัยกำลังเชื่อมโลหะภายในถัง เริ่มมีอาการเวียนศีรษะและหายใจลำบากจากสภาพอากาศภายในถัง แต่สามารถออกจากพื้นที่ได้ทันก่อนเกิดการหมดสติหรือได้รับบาดเจ็บรุนแรง                                                      | จัดเป็น Near Miss เพราะเป็นเหตุการณ์ที่เกือบเกิดอุบัติเหตุร้ายแรงจากสภาพอากาศที่ไม่ปลอดภัย แต่ยังไม่มีความสูญเสียเกิดขึ้น |
| 4. กรณีที่เป็น Accident                      | ช่างชัยได้รับผลกระทบจากการสูดดมควันเชื่อมและก๊าซพิษภายในถัง จนหมดสติจากการขาดออกซิเจนและต้องได้รับการช่วยเหลือจากทีมกู้ภัย                                                                                             | จัดเป็น Accident เพราะเกิดเหตุการณ์ที่ส่งผลกระทบต่อสุขภาพและทำให้ผู้ปฏิบัติงานได้รับอันตรายจริง                           |

เรื่องที่ 4 งานเกษตรกรรมและการใช้สารเคมีศัตรูพืช

(Agricultural Science & Pesticide Spraying)

| ประเด็นที่วินิจฉัย                                | รายละเอียดจากสถานการณ์                                                                                                                                                                                | ความหมาย / เหตุผลสนับสนุน                                                                                                   |
| -------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| 1. การกระทำที่ไม่ปลอดภัย (Unsafe Act)            | 1. ไม่สวมหน้ากากกรองสารเคมี (Respirator) 2. ไม่สวมชุดป้องกันสารเคมีและอุปกรณ์ PPE ที่เหมาะสม 3. ใช้ผ้าขาวม้าปิดจมูกแทนหน้ากากกรองสารเคมี 4. ฉีดพ่นสารเคมีในทิศทางใต้ลม ทำให้ละอองสารเคมีฟุ้งเข้าหาตัว | เป็นพฤติกรรมเสี่ยงที่ทำให้สารเคมีเข้าสู่ร่างกายผ่านทางระบบทางเดินหายใจ ผิวหนัง และดวงตา อาจทำให้เกิดพิษจากสารเคมี           |
| 2. สภาพการณ์ที่ไม่ปลอดภัย (Unsafe Condition)    | 1. สายยางของถังพ่นสารเคมีแตกลายงา 2. ข้อต่อถังพ่นยารั่วซึม 3. สารเคมีสัมผัสกับเสื้อผ้าและผิวหนังโดยตรง 4. สภาพอากาศร้อนอบอ้าวขณะปฏิบัติงาน                                                            | เป็นสภาพแวดล้อมและอุปกรณ์ที่ไม่ปลอดภัย เนื่องจากอุปกรณ์ชำรุดทำให้สารเคมีรั่วไหล และเพิ่มความเสี่ยงต่อการสัมผัสสารพิษ        |
| 3. กรณีที่เป็น Near Miss                        | ขณะที่ลุงสมหมายกำลังฉีดพ่นสารเคมี สารเคมีรั่วซึมบริเวณสายสะพายและเกือบเข้าตาหรือปาก แต่สามารถหยุดปฏิบัติงานและหลีกเลี่ยงการสัมผัสสารเคมีจนเกิดอันตรายได้                                              | จัดเป็น Near Miss เพราะเป็นเหตุการณ์ที่เกือบทำให้เกิดการสัมผัสสารเคมีที่เป็นอันตราย แต่ยังไม่มีผู้ได้รับบาดเจ็บหรือเจ็บป่วย |
| 4. กรณีที่เป็น Accident                         | ลุงสมหมายสัมผัสสารเคมีออร์กาโนฟอสเฟตผ่านผิวหนังและสูดดมละอองสารเคมีเป็นเวลานาน จนเกิดอาการพิษจากสารเคมี เช่น คลื่นไส้ เวียนศีรษะ เหงื่อออกมาก และต้องเข้ารับการรักษาในโรงพยาบาล                       | จัดเป็น Accident เพราะเกิดการสัมผัสสารเคมีจนส่งผลกระทบต่อสุขภาพจริง และต้องได้รับการรักษาพยาบาล                             |
