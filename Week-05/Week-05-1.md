
## คำถาม / แบบทดสอบทบทวน ส่วนที่ 1

**คำสั่งสำหรับนักศึกษา**  
ให้นักศึกษาอ่านเรื่องเล่าสถานการณ์ทั้ง **5 เรื่อง** ด้านล่างนี้ แล้ว **คัดเลือกทำจำนวน 3 เรื่อง** โดยนำเรื่องเล่าที่เลือกมาทำการวิเคราะห์ ถอดบทเรียน และวินิจฉัยประเด็นทางอาชีวอนามัยและความปลอดภัย (OHS Diagnosis) พร้อมกรอกข้อมูลลงใน **ตารางวิเคราะห์** ตามแบบอย่างในหัวข้อ *"ตัวอย่างเหตุการณ์และการวินิจฉัยประเด็น OHS"* 

**โครงสร้างตารางวิเคราะห์ที่ต้องกรอกส่งในแต่ละเรื่อง:**

| ประเด็นที่วินิจฉัย                                          | รายละเอียดจากสถานการณ์                     | ความหมาย / เหตุผลสนับสนุน                   |
| :---------------------------------------------------------- | :----------------------------------------- | :------------------------------------------ |
| **1. การกระทำที่ไม่ปลอดภัย (Unsafe Act)**                   | *(ระบุพฤติกรรมเสี่ยงของบุคคล)*             | *(อธิบายเหตุผลว่าขัดต่อความปลอดภัยอย่างไร)* |
| **2. สภาพการณ์ที่ไม่ปลอดภัย (Unsafe Condition)**            | *(ระบุสภาพแวดล้อม/อุปกรณ์ที่บกพร่อง)*      | *(อธิบายเหตุผลทางวิศวกรรม/สิ่งแวดล้อม)*     |
| **3. กรณีที่เป็น Near Miss (เหตุการณ์เกือบเกิดอุบัติเหตุ)** | *(สมมติฉากทัศน์เมื่อไม่มีใครเจ็บ/เสียหาย)* | *(อธิบายเหตุผลว่าทำไมจึงจัดเป็น Near Miss)* |
| **4. กรณีที่เป็น Accident (อุบัติเหตุ)**                    | *(สมมติฉากทัศน์เมื่อเกิดความสูญเสียจริง)*  | *(อธิบายเหตุผลว่าเกิดความสูญเสียอะไรบ้าง)*  |

#### เรื่องที่ 1 งานซ่อมบำรุงระบบไฟฟ้าแรงสูงในโรงงานอุตสาหกรรม (Industrial Electrical Maintenance)
**สถานการณ์**  
ช่างนพ ช่างไฟฟ้าประจำโรงงาน กำลังเร่งซ่อมแซมตู้ควบคุมไฟฟ้าแรงสูง 400V ของไลน์การผลิตหลักเพื่อลด Downtime ของโรงงาน ช่างนพไม่ได้ทำขั้นตอนการตัดตัดและแขวนป้ายเตือน (Lockout/Tagout - LOTO) และไม่ได้ใช้มัลติมิเตอร์วัดเพื่อยืนยันแรงดันเป็นศูนย์ (Zero Energy Verification) ก่อนลงมือทำงาน เพราะคิดว่าได้สับเบรกเกอร์ตัวหน้าห้องตัดไฟแล้ว ประกอบกับแผ่นพลาสติกฉนวนกั้นบัสบาร์ (Busbar Insulator) ภายในตู้ควบคุมแตกหักชำรุดจากการใช้งานมานานโดยยังไม่ได้เปลี่ยนใหม่ ปล่อยให้แท่งบัสบาร์นำไฟฟ้าลอยเปลือยเปล่า ขณะที่ช่างนพสวมเพียงถุงมือผ้าธรรมดาและยื่นมือถือไขควงเหล็กเข้าไปขันสกรูในตู้ควบคุมไฟฟ้า...

| ประเด็นที่วินิจฉัย | รายละเอียดจากสถานการณ์ | ความหมาย / เหตุผลสนับสนุน |
| :------------------------------------------------ | :------------------------------------------------ | :------------------------------------------------ |
| **1. การกระทำที่ไม่ปลอดภัย (Unsafe Act)** | *(1) ไม่ทำขั้นตอน Lockout/Tagout (LOTO)<br>(2) ไม่ใช้มัลติมิเตอร์วัดเพื่อยืนยันแรงดันเป็นศูนย์ (Zero Energy Verification)<br>(3) สวมเพียงถุงมือผ้าธรรมดาและใช้ไขควงเหล็กยื่นเข้าไปขันสกรู)* | *(ขัดต่อหลักความปลอดภัยด้านไฟฟ้าอย่างร้ายแรง เนื่องจากไม่มีการตัดและตรวจสอบกระแสไฟฟ้าอย่างถูกต้อง และเลือกใช้อุปกรณ์ที่ไม่ใช่ฉนวนไฟฟ้าในการทำงานกับไฟฟ้าแรงสูง)* |
| **2. สภาพการณ์ที่ไม่ปลอดภัย (Unsafe Condition)** | *(แผ่นพลาสติกฉนวนกั้นบัสบาร์ (Busbar Insulator) แตกหักชำรุดจากการใช้งานมานานโดยยังไม่ได้เปลี่ยนใหม่ ปล่อยให้แท่งบัสบาร์นำไฟฟ้าลอยเปลือยเปล่า)* | *(เกิดจากข้อบกพร่องทางวิศวกรรมและการบำรุงรักษา อุปกรณ์ฉนวนป้องกันชำรุดทำให้บัสบาร์เปลือย เพิ่มความเสี่ยงสูงต่อการเกิดไฟฟ้าลัดวงจรหรือ Arc Flash)* |
| **3. กรณีที่เป็น Near Miss (เหตุการณ์เกือบเกิดอุบัติเหตุ)** | *(ขณะช่างนพยื่นไขควงเหล็กเข้าไป ปลายไขควงเฉียดแท่งบัสบาร์เปลือยจนเกิดประกายไฟเล็กน้อย ช่างนพตกใจชักมือกลับทันที โดยไม่ถูกไฟฟ้าช็อตและไม่มีสิ่งใดเสียหาย)* | *(เป็นเหตุการณ์อันตรายที่มีความเสี่ยงสูง แต่ยังไม่มีผู้ได้รับบาดเจ็บและยังไม่เกิดความเสียหายต่อทรัพย์สิน)* |
| **4. กรณีที่เป็น Accident (อุบัติเหตุ)** | *(ปลายไขควงเหล็กไปสัมผัสถูกแท่งบัสบาร์เปลือยที่มีกระแสไฟ จนเกิดการระเบิดอาร์ก (Arc Flash) และไฟฟ้าช็อตช่างนพบาดเจ็บสาหัส ตู้ไฟเสียหาย และไลน์การผลิตหยุดชะงัก)* | *(เกิดความสูญเสียที่เกิดขึ้นจริง ได้แก่ การบาดเจ็บของบุคคล ทรัพย์สินเสียหาย และสูญเสียเวลาในการผลิต (Downtime))* |

#### เรื่องที่ 2 งานครัวอุตสาหกรรมและบริการอาหาร (Culinary & Food Industry)
**สถานการณ์**  
เชฟเป้ หัวหน้าเชฟครัวร้อน กำลังเร่งทอดไก่ในหม้อทอดน้ำมันลึก (Deep Fryer) อุณหภูมิ 180°C ในช่วงชั่วโมงเร่งด่วนที่มีออเดอร์ลูกค้าเข้ามารอบละหลายสิบบิล ด้วยความรีบร้อน เชฟเป้ได้นำวัตถุดิบเนื้อไก่สดที่เพิ่งนำออกจากช่องแช่แข็งแข็งซึ่งยังมีเกล็ดน้ำแข็งเกาะหนาแน่น เทลงในหม้อทอดน้ำมันร้อนจัดทันทีโดยไม่ทำการสะเด็ดน้ำและละลายน้ำแข็งออกก่อน ขณะเดียวกัน บริเวณพื้นกระเบื้องรอบหม้อทอดมีคราบน้ำมันและหยดน้ำนิ่งขังลื่น แต่ไม่มีการวางแผ่นยางกันลื่น (Anti-slip Mat) และไม่มีป้ายเตือนพื้นลื่น ขณะที่เชฟเป้กำลังยกถาดไก่ทอดลื่นไถลเสียหลัก...

| ประเด็นที่วินิจฉัย | รายละเอียดจากสถานการณ์ | ความหมาย / เหตุผลสนับสนุน |
| :------------------------------------------------ | :------------------------------------------------ | :------------------------------------------------ |
| **1. การกระทำที่ไม่ปลอดภัย (Unsafe Act)** | *(1) นำเนื้อไก่สดที่มีเกล็ดน้ำแข็งเกาะหนาแน่นเทลงหม้อทอดน้ำมันร้อน 180°C ทันทีโดยไม่สะเด็ดน้ำและละลายน้ำแข็งออกก่อน<br>(2) ยกถาดไก่ทอดเดินด้วยความรีบร้อนบนพื้นที่เสี่ยงลื่น)* | *(ขัดต่อความปลอดภัยในงานครัว เนื่องจากน้ำแข็งทำให้น้ำมันร้อนพุ่งกระจายอย่างรุนแรง และการรีบร้อนเดินบนพื้นลื่นเพิ่มความเสี่ยงต่อการเสียหลักลื่นไถล)* |
| **2. สภาพการณ์ที่ไม่ปลอดภัย (Unsafe Condition)** | *(1) พื้นกระเบื้องรอบหม้อทอดมีคราบน้ำมันและหยดน้ำนิ่งขังลื่น<br>(2) ไม่มีแผ่นยางกันลื่น (Anti-slip Mat) และไม่มีป้ายเตือนพื้นลื่น)* | *(สภาพแวดล้อมไม่ปลอดภัยจากการปนเปื้อนของน้ำและน้ำมันบนพื้น ขาดการควบคุมทางวิศวกรรม (แผ่นยางกันลื่น) และขาดป้ายเตือนอันตราย)* |
| **3. กรณีที่เป็น Near Miss (เหตุการณ์เกือบเกิดอุบัติเหตุ)** | *(เชฟเป้ก้าวเท้าลื่นคราบน้ำมันจนเสียหลัก แต่สามารถทรงตัวดึงจังหวะกลับมาได้ ถาดไก่ทอดไม่ตก และน้ำมันร้อนไม่กระเด็นใส่)* | *(เป็นเหตุการณ์เกือบเกิดอุบัติเหตุจากการเสียหลักลื่นไถล แต่ยังไม่มีผู้ได้รับบาดเจ็บและไม่มีทรัพย์สินเสียหาย)* |
| **4. กรณีที่เป็น Accident (อุบัติเหตุ)** | *(เชฟเป้ลื่นคราบน้ำมันล้มลง ถาดไก่ทอดหลุดมือ และตัวปะทะหม้อทอด ทำให้น้ำมันร้อน 180°C ราดใส่ร่างกาย เกิดแผลไฟลวกระดับรุนแรง)* | *(เกิดความสูญเสียจริง ได้แก่ ร่างกายได้รับบาดเจ็บรุนแรง วัตถุดิบและอุปกรณ์เสียหาย รวมถึงเสียเวลาในการให้บริการ)* |

#### เรื่องที่ 3 งานเชื่อมตัดโลหะในสถานที่อับอากาศ (Welding in Confined Space)
**สถานการณ์**  
ช่างชัย ได้รับมอบหมายให้เข้าไปเชื่อมซ่อมแซมรอยแตกร้าวภายในถังเหล็กบรรจุสารเคมีขนาดใหญ่ (Confined Space) ช่างชัยไม่ได้ทำการตรวจวัดระดับก๊าซพิษและปริมาณออกซิเจนก่อนเข้าไป และไม่ได้พกอุปกรณ์ช่วยหายใจ (SCBA) หรือท่อส่งอากาศสดภายนอกเข้าไปด้วย เพราะคิดว่าเป็นงานเชื่อมจุดเล็กๆ ใช้เวลาไม่เกิน 10 นาที ประกอบกับพัดลมระบายอากาศ (Blower) สำหรับระบายอากาศถังบรรจุชำรุดเสียหายทำให้ไม่มีการถ่ายเทอากาศสดภายในถัง ขณะที่ช่างชัยจุดหัวเชื่อมแก๊สอาร์กอนและเริ่มตกกระทบอาร์กเปลวไฟประกายไฟสะเก็ดเชื่อมฟุ้งกระจายภายในถังปิด...

| ประเด็นที่วินิจฉัย | รายละเอียดจากสถานการณ์ | ความหมาย / เหตุผลสนับสนุน |
| :------------------------------------------------ | :------------------------------------------------ | :------------------------------------------------ |
| **1. การกระทำที่ไม่ปลอดภัย (Unsafe Act)** | *(1) เข้าสถานที่อับอากาศโดยไม่ตรวจวัดระดับก๊าซพิษและปริมาณออกซิเจนก่อน<br>(2) ไม่พกอุปกรณ์ช่วยหายใจ (SCBA) หรือท่อส่งอากาศสด<br>(3) จุดหัวเชื่อมแก๊สอาร์กอนโดยประเมินความเสี่ยงผิดพลาด)* | *(ฝ่าฝืนกฎหมายความปลอดภัยในสถานที่อับอากาศ การไม่ตรวจวัดบรรยากาศ ไม่ใช้อุปกรณ์ป้องกันทางเดินหายใจ และจุดประกายไฟ เสี่ยงต่อการขาดอากาศหรือเกิดการระเบิด)* |
| **2. สภาพการณ์ที่ไม่ปลอดภัย (Unsafe Condition)** | *(1) พัดลมระบายอากาศ (Blower) ชำรุดเสียหายทำให้ไม่มีการถ่ายเทอากาศสด<br>(2) พื้นที่ทำงานเป็นถังเหล็กบรรจุสารเคมีปิดล็อก สะสมประกายไฟและความร้อน)* | *(บกพร่องทางวิศวกรรมเนื่องจากระบบระบายอากาศชำรุด ทำให้สภาพแวดล้อมกลายเป็นสถานที่อับอากาศที่ขาดออกซิเจนและสะสมก๊าซอันตราย)* |
| **3. กรณีที่เป็น Near Miss (เหตุการณ์เกือบเกิดอุบัติเหตุ)** | *(ขณะจุดหัวเชื่อมเกิดไฟวาบเล็กน้อย และช่างชัยเริ่มมึนศีรษะ จึงรีบปีนออกจากถังได้ทันโดยยังไม่หมดสติและไม่ได้รับบาดเจ็บ)* | *(เป็นภาวะวิกฤตที่เกือบเกิดการระเบิดหรือหมดสติ แต่สามารถหลบหนีได้ทันจึงยังไม่มีการบาดเจ็บหรือเสียชีวิต)* |
| **4. กรณีที่เป็น Accident (อุบัติเหตุ)** | *(ประกายไฟเชื่อมจุดติดก๊าซเคมีตกค้างจนเกิดการระเบิด ช่างชัยบาดเจ็บสาหัส มีแผลไหม้ทั่วตัว และหมดสติภายในถังจากการขาดออกซิเจน)* | *(เกิดความสูญเสียร้ายแรงจริง ได้แก่ การบาดเจ็บสาหัสอันตรายถึงชีวิต และความเสียหายทางทรัพย์สินอย่างหนักต่อถังบรรจุสารเคมี)* |
