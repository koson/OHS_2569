## 📝 สรุปเรื่องราว (Overview)
วันที่ฝนตก ด้วยความเร่งรีบไปทำงานทำให้ขับรถด้วยความเร็ว จนเกิดเหตุการลื่นตรงโค้งหน้าโรงงานเพราะทางเลี้ยวหน้าป้อมยามมีการทาสีใหม่ทำให้ถนนลื่น ทำให้เกิดอาการบาดเจ็บภายในที่ข้อเท้าจากการโดนรถทับ
