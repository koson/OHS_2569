## Homework: วิเคราะห์ Danger / Accident / Near Miss
จาก Hazard ที่กำหนด ให้คุณวิเคราะห์ 3 มิติ ได้แก่
- Danger (อันตรายที่อาจเกิดขึ้น)
- Accident (เหตุการณ์ที่เกิดขึ้นจริง)
- Near Miss (เหตุเฉียดที่เกือบเกิด แต่ยังไม่เกิด)
ให้เขียนลงในตารางที่กำหนด โดยใช้ภาษาของตัวเอง ห้ามท่องนิยาม ห้ามคัดลอกทฤษฎี ให้เขียนแบบภาษาคนทั่วไป เหมือนเล่าเหตุการณ์ให้เพื่อนฟัง
สามารถส่งตรวจคราวเดียวทั้งหมดหรือครั้งละหมวดก็ได้
คุณสามารถส่งคำตอบใหม่ได้เรื่อยๆ จนกว่าจะพอใจคะแนน TA AI จะตรวจให้ทุกครั้งแบบเข้มงวด

## แนวทางการเขียน Danger, Accident และ Near Miss
### 👉 วิธีเขียน Danger ให้ถูกต้อง
Danger = “โอกาสที่จะเกิดเหตุ” ต้องมี **สถานการณ์เฉพาะเจาะจง** เช่น
- ตอนเดินถือของร้อน
- ตอนเดินสวนกันในครัวแคบ
- ตอนรีบทำงาน
ห้ามเขียนว่า “มีโอกาสลื่นล้ม” เฉย ๆ เพราะมันสั้นเกินไป ต้องระบุสถานการณ์ที่เจาะจงด้วย

### 👉 วิธีเขียน Accident ให้ถูกต้อง
Accident = “เหตุการณ์จริงที่เกิดขึ้นแล้ว” ต้องมี **ลำดับเหตุการณ์** เช่น
1. เหยียบน้ำมัน
2. ลื่นล้ม
3. มือกระแทกกระทะร้อน
4. อาหารหก
ห้ามเขียนว่า “ลื่นล้มเพราะเดินไม่ระวัง” เพราะเป็นการโทษคน และไม่ใช่หลัก OHS

### 👉 วิธีเขียน Near Miss ให้ถูกต้อง
Near Miss = “เกือบเกิด แต่ไม่เกิด” ต้องมี **สิ่งที่ช่วยให้ไม่เกิดเหตุ** เช่น
- จับโต๊ะทัน
- ยกเท้าหลบทัน
- เพื่อนดึงตัวไว้
ห้ามเขียนว่า “เกือบล้ม” เฉย ๆ ต้องบอกว่า “เพราะอะไรถึงไม่ล้ม”

### K1. พื้นครัวมันลื่นเพราะน้ำมันกระเด็นตอนผัดไฟแรง
#### คำตอบ (ตัวอย่าง)

| รายการ    | รายละเอียด                                                                                                                                    |
| --------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| Danger    | พนักงานมีโอกาสลื่นล้มตอนเดินถือจานร้อน โดยเฉพาะช่วงที่ครัวแคบและต้องเดินสวนกัน เพราะพื้นมีน้ำมันเคลือบอยู่ทำให้เท้าไถลง่าย                    |
| Accident  | พนักงานเดินถือชามร้อนแล้วเหยียบน้ำมัน ทำให้ลื่นล้ม มือกระแทกกระทะร้อนจนพอง และอาหารหกกระจายเต็มพื้น เกิดความเสียหายทั้งต่อร่างกายและงานในครัว |
| Near Miss | พนักงานเดินผ่านจุดที่มีน้ำมันแล้วรู้สึกเท้าไถล แต่จับโต๊ะทันเลยไม่ล้ม เหตุการณ์นี้เกือบจะกลายเป็นอุบัติเหตุจริง แต่โชคดีที่ควบคุมตัวเองได้ทัน |

| Near Miss | คนงานเดินคุยกันเผลอก้าวไปชิดขอบหลุมลึก จังหวะนั้นดินปากหลุมร่วนทรุดฮวบ แต่โชคดีที่เพื่อนข้างๆ คว้าคอเสื้อดึงกระชากกลับหลังมาทันเลยไม่ล่วงลงไป           |
### T5. พนักงานยืนคุยกันในจุดบอดของรถบรรทุก
#### คำตอบ
| รายการ    | รายละเอียด |
| --------- | ---------- |
| Danger    | พนักงานมีโอกาสโดนรถบรรทุกชนหรือเหยียบซ้ำ ตอนที่คนขับสตาร์ทเครื่องแล้วเหยียบคันเร่งออกตัวโดยมองไม่เห็นคนที่ยืนอยู่ท้ายรถ/ข้างตัวรถ         |
| Accident  |  พนักงาน 2 คนยืนคุยกันตรงท้ายรถบรรทุกสิบล้อ คนขับขึ้นรถมองกระจกมองหลังไม่เห็นเลยเข้าเกียร์ถอยหลังชนพนักงานล้มคว่ำและเหยียบกระดูกเชิงกรานหัก          |
| Near Miss | คนขับรถบรรทุกกำลังจะเข้าเกียร์ถอยหลัง แต่โชคดีที่ตะโกนด่า คันข้างๆ แล้วพนักงานยินเสียงเบิ้ลเครื่องยนต์เลยรีบกระโดดวงแตกแยกย้ายหนีพ้นท้ายรถทัน           |
### T6. รถเข็นขนของมีล้อแตกแต่ยังใช้งาน
#### คำตอบ
| รายการ    | รายละเอียด |
| --------- | ---------- |
| Danger    |รถเข็นมีโอกาสเสียหลักพลิกคว่ำ ของหนักเทกระจาดทับพนักงานตอนที่ต้องเข็นผ่านพื่นที่ขรุขระหรือพื้นที่ลาดชัน            |
| Accident  |  พนักงานเข็นกล่องสินค้าหนัก 80 กิโลลงทางลาด จังหวะนั้นล้อที่แตกเกิดขัดขัดล็อกตาย รถเข็นสะบัดพลิกคว่ำกล่องสินค้าร่วงหล่น ทับขาพนักงานจนข้อเท้าแพลงฉีกขาด        |
| Near Miss | พนักงานเข็นรถล้อแตกรู้สึกรถฝืดๆ และเอียงยวบทำท่าจะล้มครืนแต่พนักงานทิ้งน้ำหนักตัวโหนทิ้งด้ามจับเบรกยื้อรถไว้ทัน ของเอียงแต่ไม่คว่ำลงพื้น           |
### T7. พนักงานยกกล่องหนักขึ้นรถโดยไม่มีท่าทางที่ถูกต้อง
#### คำตอบ
| รายการ    | รายละเอียด |
| --------- | ---------- |
| Danger    |  พนักงานมีโอกาสหลังยอก เส้นเอ็นหลังอักเสบเฉียบพลัน ตอนที่ก้มหลังตรงลงไปดึงยกกล่องสินค้าหนักขึ้นจากพื้นโดยไม่ย่อเข่า          |
| Accident  |พนักงานก้มตัวเอื้อมยกกล่องอะไหล่เหล็กหนักขึ้นท้ายรถกระบะ จังหวะออกแรงดึงเกิดอาการหลังลั่นเปรี้ยะ หมอนรองกระดูกทับเส้น ล้มฟุบร้องโอดโอยขยับตัวไม่ได้            |
| Near Miss |พนักงานลองออกแรงยกกล่องแล้วรู้สึกเสียววาบที่กล้ามเนื้อเอวเลยรีบปล่อยของลง ย่อเข่าตั้งหลักจัดท่าใหม่แล้วค่อยยก ทำให้อาการไม่บานปลาย            |
### T8. พื้นลานโหลดมีน้ำขังจากฝนตก

| --------- | ---------- |
| Danger    |  พนักงานมีโอกาสลื่นไถลหงายหลังตอนแบกของขึ้นรถ หรือรถโฟล์คลิฟต์วิ่งมาแล้วเบรกไม่อยู่ไถลชนคน ตอนที่ต้องทำงานแข่ง กับเวลา          |
| Accident  |  พนักงานเดินอุ้มล้อแม็กซ์รถยนต์ก้าวผ่านแอ่งน้ำฝน เท้าลื่นพรืดเสียหลักล้มก้นกระแทกเหล็ก ล้อแม็กซ์ร่วงหล่นมากระแทกหน้าอก

### T12. พนักงานขี่มอเตอร์ไซค์ในลานขนส่งโดยไม่ใส่หมวกกันน็อก
