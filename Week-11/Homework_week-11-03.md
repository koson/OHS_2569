1. จงอธิบายความแตกต่างระหว่าง "การตรวจความปลอดภัยแบบต่อเนื่อง (Continuous Inspection)" และ "การตรวจความปลอดภัยตามกำหนดเวลา (Periodic Inspection)" ทั้งในด้านผู้รับผิดชอบและความถี่

1.1 ความถี่ :

1.1.1 การตรวจแบบต่อเนื่อง : ดำเนินการเป็นประจำทุกวันหรือทุกกะการทำงาน
1.1.2 การตรวจตามกำหนดเวลา : ดำเนินการตามรอบเวลาที่กำหนดไว้แน่นอน เช่น ทุกเดือน, ทุก 3 เดือน หรือทุกปี

1.2 ผู้รับผิดชอบ :

1.2.1 การตรวจแบบต่อเนื่อง : พนักงานประจำเครื่องและหัวหน้างาน
1.2.2 การตรวจตามกำหนดเวลา : คณะกรรมการความปลอดภัย อาชีวอนามัย และสภาพแวดล้อมในการทำงาน (คปอ.), เจ้าหน้าที่ความปลอดภัยในการทำงาน (จป.) ระดับวิชาชีพ หรือวิศวกรผู้เชี่ยวชาญ

1.3 ขอบเขตการตรวจ :

1.3.1 การตรวจแบบต่อเนื่อง : เน้นตรวจสอบความพร้อมและสภาพของอุปกรณ์ก่อนเริ่มงาน ความสะอาดเรียบร้อย และพฤติกรรมการทำงาน
1.3.2 การตรวจตามกำหนดเวลา : เน้นตรวจสอบระบบและเครื่องจักรขนาดใหญ่ เช่น หม้อน้ำ (Boiler), เครน/ปั้นจั่น หรือระบบดับเพลิง

2. หากสถานประกอบกิจการมีลูกจ้างรวมทั้งสิ้น 250 คน กฎหมายไทยกำหนดให้ต้องจัดให้มีคณะกรรมการความปลอดภัยฯ (คปอ.) จำนวนขั้นต่ำกี่คน และมีสัดส่วนผู้แทนฝ่ายใดบ้าง?

กฎหมายไทยกำหนดให้สถานประกอบกิจการที่มีลูกจ้าง 200–499 คน ต้องมีคณะกรรมการ คปอ. ไม่น้อยกว่า 7 คน ประกอบด้วยสัดส่วนผู้แทน ดังนี้:

1. ประธานกรรมการ : นายจ้างหรือผู้แทนนายจ้างระดับบริหาร จำนวน 1 คน
2. ผู้แทนนายจ้างระดับบังคับบัญชา : จำนวน 2 คน
3. ผู้แทนลูกจ้างระดับปฏิบัติการ : (มาจากการเลือกตั้ง) จำนวน 3 คน
4. เลขานุการ : เจ้าหน้าที่ความปลอดภัยในการทำงาน (จป.) ระดับวิชาชีพ จำนวน 1 คน

3. เพราะเหตุใดองค์กรจึงต้องให้ความสำคัญกับการสอบสวน "เหตุการณ์เกือบเกิดอุบัติเหตุ (Near-Miss)" เท่าเทียมกับอุบัติเหตุที่เกิดการบาดเจ็บจริง? จงอธิบายโดยอ้างอิงทฤษฎีสามเหลี่ยมอุบัติเหตุของเบิร์ด

ตามทฤษฎีสามเหลี่ยมอุบัติเหตุของ แฟรงก์ อี. เบิร์ด ในสัดส่วน 1 : 10 : 30 : 600 ชี้ให้เห็นว่า ภายใต้อุบัติเหตุร้ายแรงหรือการเสียชีวิต 1 ครั้ง จะมีเหตุการณ์เกือบเกิดอุบัติเหตุ เกิดขึ้นถึง 600 ครั้ง ซึ่งเหตุการณ์ Near-Miss เหล่านี้เกิดจากสาเหตุรากเหง้า และความบกพร่องในระบบการทำงานเดียวกัน หากองค์กรตรวจพบและทำการสอบสวนแก้ไขตั้งแต่ขั้น Near-Miss จะสามารถตัดวงจรและป้องกันไม่ให้อันตรายพัฒนาไปสู่อุบัติเหตุร้ายแรง การสูญเสียชีวิต หรือทุพพลภาพได้

4. โรงงานผลิตชิ้นส่วนอิเล็กทรอนิกส์แห่งหนึ่ง มีพนักงาน 500 คน ทำงานเฉลี่ยคนละ 2,000 ชั่วโมงต่อปี ในรอบปีที่ผ่านมาเกิดอุบัติเหตุถึงขั้นหยุดงาน 5 ครั้ง มีวันหยุดงานรวม 40 วัน จงคำนวณหาค่า LTIFR และ LTISR ของโรงงานแห่งนี้

1. คำนวณชั่วโมงการทำงานรวมของลูกจ้างทั้งหมด (Total Man-Hours) :

Total Man-Hours = 500 คน x 2,000 ชั่วโมง/คน/ปี = 1,000,000 ชั่วโมง

2. คำนวณอัตราความถี่ของการเกิดอุบัติเหตุถึงขั้นหยุดงาน (LTIFR) :

LTIFR} = (จำนวนครั้งของการบาดเจ็บถึงขั้นหยุดงาน x 1,000,000) หารด้วย Total Man-Hours = (5 x 1,000,000) หารด้วย 1,000,000 = 5 ครั้ง / 1,000,000 ชั่วโมงทำงาน


3. คำนวณอัตราความรุนแรงของการเกิดอุบัติเหตุ (LTISR) :

LTISR = (จำนวนวันทำงานที่สูญเสียรวม x 1,000,000) หารด้สย Total Man-Hours = (40 x 1,000,000) หารด้วย 1,000,000 = 40.0 วัน / 1,000,000 ชั่วโมงทำงาน
